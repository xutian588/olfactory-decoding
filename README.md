# LNDN: Long-term Neural Decoding Network

Code repository for **“Multi-Level Alignment Framework for
Long-Term Olfactory Neural Decoding.”**

## Overview

LNDN is a hierarchical framework for long-term olfactory neural
decoding without cross-session neuron tracking or periodic
supervised recalibration.

The framework combines physical feature encoding and dynamic
gating, Mixture-of-Experts population readouts, and manifold-level
alignment with test-time Adaptive Batch Normalization.

## Code Availability
